School Carpool Timer
A simple app to calculate when you need to leave for school carpool.

How to Host on GitHub Pages
Step 1: Create a GitHub Repository
Go to GitHub and sign in
Click the + button in the top right, then New repository
Name it something like carpool-timer
Make it Public
Click Create repository
Step 2: Upload Your Files
On your new repository page, click uploading an existing file
Drag and drop the index.html file
Click Commit changes
Step 3: Enable GitHub Pages
In your repository, click Settings (top menu)
Click Pages in the left sidebar
Under "Source", select main branch
Click Save
Wait a minute, then refresh the page
You'll see a message with your site URL: https://[your-username].github.io/carpool-timer/
That's it!
Your carpool timer will be live at that URL. You can bookmark it on your phone for easy morning access.

Using the App
Set your arrival time (defaults to 8:45 AM)
Check/uncheck which kids need rides
Check/uncheck if you need to scrape ice
The app calculates when you need to start!
